02 / Semantic Colors

Distinct purpose-driven scales. Do not reuse Royal Cobalt for system success or danger states.

Room status is a product-specific model, not the same thing as system feedback: Vacant = available/green; Occupied = blue/neutral; Reserved = amber; On notice = amber with date; Out of service = red with explicit text. Never rely on color alone.

03 / Typography

Manrope is the only primary font. Headings use tighter letter spacing; data and currency use tabular numerals for alignment.

Weights: 400 regular · 500 medium · 600 semibold · 700 bold · 800 extra bold. Body default: 16px / 24px; dense data tables: 14px / 20px; accessible minimum supporting labels: 12px.

04 / Spacing & Size

Consistent 4px rhythm. Common gaps: 8, 12, 16, 24, 32. Default card padding: 20–24px. Mobile page gutters: 16px; desktop content gutters: 24–40px.

12 / Accessibility & Usage Rules

Contrast

Meet WCAG AA: 4.5:1 for regular text and 3:1 for large text and critical UI boundaries. Royal Cobalt #3154D9 on white provides strong contrast for primary buttons and links.

Interaction

Use visible focus rings, keyboard support, descriptive button labels and at least 44px touch targets for mobile resident experiences.

Communication

Never use color alone for payment state, bed state, notice days, or critical errors. Add text, icon and where useful date or amount.

Responsive

Desktop sidebar plus table; tablet collapsible navigation; mobile lists/cards for resident-facing actions, with no horizontal clipping.

Typography

Manrope throughout; body text ideally 16px; line height at least 1.5 for paragraph text. Enable tabular numerals for financial figures.

Motion

Subtle feedback only; honor prefers-reduced-motion. Avoid animation on urgent bills and financial statuses.
